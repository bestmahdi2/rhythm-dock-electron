Start listening

Open an audio file or choose your music folder. Use Player, Playlist and Settings, and open Tools from Settings. Ctrl+K (Cmd+K on macOS) finds actions.

Listen together

Create a room, invite your friend and share a queue. Phones can join in their browser. Server credentials are configured separately.

Audio and practice

Use multiple outputs, EQ, loops and a count-in. Optional FFmpeg enables waveform generation, conversion and edited exports.

Prioritized checklist

Protect your library

Library backups include ratings, playlists, history and bookmarks. File changes require a preview; tag undo restores saved bytes. Organization moves audio files only, so retain companion lyrics and CUE sheets when organizing albums.

Verification

Run npm test and npm run test:ui-smoke in the app directory. The test guide covers optional FFmpeg and platform requirements. Live service and hardware acceptance remain separate.
